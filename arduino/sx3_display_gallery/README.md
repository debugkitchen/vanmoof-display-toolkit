# SX3 Display — Firmware Image Gallery

Rotates through all 54 original VanMoof images and animations, extracted
from `mainware_1_9_3.bin`. Each image plays through completely at its real
per-frame durations, followed by a 1 s black pause, then the next image.
Loops forever; the current image name is printed to Serial.

The images live in `sx3_images_all.h`, generated by
[`firmware-tools/extract_images.py`](../../firmware-tools/extract_images.py)
from the same firmware dump as the web editor's
[gallery](../../editor/gallery/README.md) — names match exactly between the
two (e.g. `angry_skull`, `low_battery_two_digits`, `region_eu`).

## Wiring

| Signal | ESP32-C3 GPIO |
|--------|---------------|
| SDA    | GPIO4         |
| SCL    | GPIO3         |
| SDB    | GPIO2         |
| 5V     | 5V            |
| 3V3    | 3V3           |
| GND    | GND           |

Same wiring as every other sketch in `arduino/` — see the
[guide](../../guide/README.md#2-the-connector-and-how-to-wire-it-up) for the
full connector pinout.

## Flashing

1. Open `sx3_display_gallery.ino` in the Arduino IDE — it needs
   `sx3_images_all.h` in the same sketch folder (already there).
2. Select an ESP32-C3 board (e.g. **ESP32C3 Super Mini** / ESP32-C3 Dev Module).
3. **Tools → USB CDC On Boot → Enabled**.
4. Upload, then open the Serial Monitor at 115200 baud to see which image is
   currently showing and its frame/timing details.

## Regenerating `sx3_images_all.h`

You only need this if you want to extract images from a different firmware
build. Run `firmware-tools/extract_images.py` against your own
`mainware_*.bin` (not distributed with this repo) — see that script's
docstring for usage. It reads the image list from
`editor/gallery/firmware_gallery.json`, so re-run the web editor's naming
tool first if you want a different set of images.
